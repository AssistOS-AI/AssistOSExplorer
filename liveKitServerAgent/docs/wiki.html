LiveKit Server terminology

LiveKit Server

The media server supervised by AchillesIDE/liveKitServerAgent. It carries live meeting media on the Box's single UDP 7882 mux while Ploinky Router mediates signaling and private administration.

Egress

The supervised LiveKit recording process. Its private template listener and semantic health listener have separate roles; a successful recording requires connected publisher media and completed non-empty output.

Topology

The immutable Ploinky runtime snapshot that selects the current media address and publication generation. Configuration generation consumes it only after Router authority attestation.

TURN

An external relay service for media connectivity. Ploinky brokers short-lived credentials for authorized consumers; this agent does not run a relay or hold its long-term secret.
