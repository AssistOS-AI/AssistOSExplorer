## Introduction

RoboWork runs the robots controlled through RoboTeam while keeping their homes separate.

## Core Content

Users keep their robot's native accounts and files between disposable execution environments. RoboTeam remains the controller for conversations, tasks, GUI actions and workflows. RoboWork owns homes, ALA processes, terminals, GUI containers, selected-image environments and shared tool generations. The split preserves these workflows while removing direct access to sibling homes and agent credentials from robot programs.
