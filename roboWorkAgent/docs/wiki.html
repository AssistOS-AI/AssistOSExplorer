Wiki

Robot

A robot is a workspace identity registered by RoboTeam. RoboWork owns its persistent home, native account configuration and runtime resources. Programs see that home at /home/<id>; sibling homes are outside their filesystem view. Robot homes may contain credentials and executable configuration. An administrator retains all-home access through a plain RoboWork terminal.

Run

A run is one resident RoboWork execution identified by a run ID and associated with a robot, session and turn. RoboTeam starts and controls it through internal tools. Service-owned metadata and sequence-numbered logs support reattachment after a RoboTeam restart. Project records select a run but cannot authorize it. RoboWork restart interrupts it; Resume uses the saved native conversation.

Git credential

A git credential is a GitHub token, with git user name and email, that RoboTeam saved for one robot. RoboWork stores it encrypted outside the robot's directories and serves it only to git's credential helper in that robot's processes, over the robot's own socket, for https://github.com. It is never written to the robot home. The default robot's token is stored only in Ploinky's workspace git credential file, shared with Ploinky's own git operations.

Environment

An Environment is a short-lived container started from an enabled global agent's declared image. It supplies that image's programs with the selected robot's home and admitted project folder. It does not execute inside the live target agent and receives no target credentials, target localhost or programs installed after startup. Discovery excludes private-data agents and downloads only the image selected for execution.
