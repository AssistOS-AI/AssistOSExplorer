SOPLang Runtime Boundary

soplangAgent exposes that runtime through Model Context Protocol (MCP). It bridges workspace application programming interfaces (APIs) and runtime plugins into a stable tool surface declared in soplangAgent/mcp-config.json, while command registration, build orchestration, and skill discovery remain on the agent side.

Runtime Behavior

At runtime each MCP tool call is executed through soplangAgent/soplang-tool.sh. Explorer and related flows call the agent for build and execution tasks, while SOPLang-specific orchestration stays inside soplangAgent rather than leaking into document plugins or toolbar code. Active Markdown discovery excludes private .data trees while retaining the public root .ploinky/repos source mount. Runtime logs last-tool.log and achilles-debug.log stay under the configured LOGS_FOLDER, defaulting to $HOME/.soplang/logs.

The Advanced Editor SCRIPTA plugin is a thin adapter over Explorer's shared, whitelisted variants component. The shared component renders tabs, votes, and proposals; the plugin retains document identity and persistence through the Advanced Editor presenter. Variants use canonical p-variant-* operations: everyone may vote, while only the participant who added a variant may edit or delete it.

Validation rule: run npm test from soplangAgent/ for every code change, together with docs and specs updates.
