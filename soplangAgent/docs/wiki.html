SOPLang terminology

SOPLang

SOPLang is the agent-owned language and execution pipeline for structured procedure documents. Its tools parse or build the document representation, resolve declared variables and actions, and return execution results while Explorer supplies the editing and plugin surface.

Model Context Protocol

Model Context Protocol is the configured tool boundary used by the agent. Tool names and input schemas come from the local MCP configuration and execution remains subject to the agent's verified runtime authorization.

Ploinky

Ploinky starts the agent, supplies its runtime environment, and mediates authenticated invocation context. The agent does not treat client-declared identity as authorization.

UI bridge

The user interface (UI) bridge connects SOPLang Explorer plugins to the agent's tool contract. It carries the selected workspace document and action context but leaves parsing, validation, and domain mutation in the agent.

Procedure document

A procedure document is the structured SOPLang source operated on by the builder and execution tools. Its declared chapters, paragraphs, variables, and actions are distinct from Explorer's generic file-navigation state.
