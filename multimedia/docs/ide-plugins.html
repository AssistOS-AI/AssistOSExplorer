IDE Plugin Surface

This agent is effectively a catalog of IDE plugins for media attachments and video preview inside document editing workflows.

Published Plugin Matrix

Plugin Location Type Purpose
audio-plugin chapter, paragraph modal Upload, edit, and delete audio attachments with per-action progress feedback.
image-plugin chapter, paragraph modal Upload and manage image attachments with metadata and per-action progress feedback.
video-plugin chapter, paragraph modal Upload and edit video attachments (start/end/volume/loop) with per-action progress feedback.
files-menu paragraph modal Attach generic files, download, and remove them with per-action progress feedback.
ffmpeg-image-to-video chapter, paragraph modal Builds ffmpegImageToVideo commands directly from existing attachments.
video-creator contextual embedded Trim/volume/lipsync/compile controls for paragraph video.
paragraph-video-preview contextual embedded Fast preview for the current paragraph scene.
document-video-preview document embedded Sequential preview for the entire document.

Shared Utilities

The plugins share infrastructure from IDE-plugins/utils for blob upload, URL building, metadata extraction, and document/chapter/paragraph context resolution.

audio-creator exists in code, but audio-creator/config.json is empty, so the plugin is not published through the standard config contract.
