Multimedia terminology

Multimedia agent

The Multimedia agent supplies Explorer document plugins for media preview and creation and runs the corresponding media-processing operations. Explorer owns placement and file context; the agent owns the FFmpeg-backed transformation and returns workspace artifacts rather than embedding processing logic in the browser.

Model Context Protocol

Model Context Protocol is the configured tool boundary used by the agent. Tool names and input schemas come from the local MCP configuration and execution remains subject to the agent's verified runtime authorization.

Ploinky

Ploinky starts the agent, supplies its runtime environment, and mediates authenticated invocation context. The agent does not treat client-declared identity as authorization.

IDE plugin

An integrated development environment (IDE) plugin is a manifest-declared Explorer extension mounted into an allowed document or application slot. Multimedia plugins contribute media-specific controls while Explorer retains routing, layout, and component lifecycle ownership.

FFmpeg

FFmpeg is the command-line media engine used by the agent's implemented conversion and composition paths. Tool inputs determine the requested operation, while workspace path validation constrains source and output files.
