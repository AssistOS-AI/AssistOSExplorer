Stripe payments

Connect Stripe to receive payments. Per-credit prices and user point awards are managed in the ScriptaHub Dashboard.

Stored secrets are never displayed. Leave a secret field empty to keep its current value.

Add this webhook address in Stripe and select checkout.session.completed, checkout.session.async_payment_succeeded and checkout.session.async_payment_failed. For localhost, use Stripe CLI forwarding; for a publicly reachable site, Stripe can send events directly.
