# Google sign-in assets

The sign-in wizard and the reauth confirmation page use Google's own rendered button through the current [Google Identity Services SDK](https://developers.google.com/identity/gsi/web/guides/get-google-api-clientid) at `https://accounts.google.com/gsi/client`. The supported SDK loads from Google so security and compatibility updates remain current; an offline or self-hosted copy is unsupported. The served SDK has no repository pin or local modification. Its use is governed by [Google APIs Terms of Service](https://developers.google.com/terms), applicable Identity terms and Google's branding rules, not the MIT license of server dependencies or the licenses attached to documentation samples.

The OIDC sign-in page permits the SDK, its Google frames/styles and account images in its CSP, uses `same-origin-allow-popups`, and supplies the referrer policy required by the selected HTTPS or localhost deployment only while Google is available; the reauth page always does. Resume and dashboard pages do not load the SDK. The browser callback sends the ID token directly to the same-origin verifier; credentials never enter URLs, browser storage or logs. The shared helper `google-gis.js` leaves the SDK unmodified and only enlarges the popup the SDK opens to Google's accounts origin, keeping its URL, target and other window features, so Google's account, passkey and consent screens fit without scrolling.

Google's SDK-rendered button (standard type, outline theme, large, “Sign in with Google” text) is the first control on the opening screen, above the **Email** field and **Next**; there is no local entry button or intermediate page. The local button assets below remain in the repository but are not used by the sign-in wizard.

`google-button-icon.png` is the unmodified Android + Web, light, square, icon-only PNG at 4x from Google's [pre-approved asset archive](https://developers.google.com/static/identity/images/signin-assets.zip). CSS displays the central G at its original proportions inside the complete labelled button; the source PNG is unchanged. Google brand features remain subject to Google's branding terms.

`google-sans-medium.ttf` is the weight-500 Google Sans file served by the [Google Fonts CSS API](https://fonts.googleapis.com/css2?family=Google+Sans:wght@500&display=swap), stored locally so sign-in makes no third-party font request. The SIL Open Font License is included in `google-sans-OFL.txt` from the [Google Sans source repository](https://github.com/googlefonts/googlesans).
