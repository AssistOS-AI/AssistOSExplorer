WebAssist terminology

WebAssist

WebAssist is the visitor-facing conversation agent for site sessions, qualification, lead capture, and meeting escalation. It loads the configured site context, updates one persisted visitor session, and exposes the same domain behavior through its command-line and Model Context Protocol entry paths.

Model Context Protocol

Model Context Protocol is the configured tool boundary used by the agent. Tool names and input schemas come from the local MCP configuration and execution remains subject to the agent's verified runtime authorization.

Ploinky

Ploinky starts the agent, supplies its runtime environment, and mediates authenticated invocation context. The agent does not treat client-declared identity as authorization.

Visitor session

A visitor session is the durable conversation and profile state associated with one site visitor. WebAssist loads that state before responding and applies validated updates so later turns preserve qualification context.

Lead

A lead is the qualified contact outcome produced from an eligible visitor session. Lead creation follows the configured skill and session rules; ordinary conversation does not automatically become a lead.
