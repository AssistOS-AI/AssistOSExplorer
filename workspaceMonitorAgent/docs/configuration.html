Configuration

The manifest starts server/supervisor.mjs, declares administrator access to workspace logs, and mounts persistent storage at /data. WORKSPACE_MONITOR_DATA_ROOT points the agent to that storage root.

SettingDefaultValidation
workspaceCpuPercent80Finite number from 0 to 100,000.
workspaceMemoryBytes4 GiBPositive finite number.
routerCpuPercent80Finite number from 0 to 100,000.
routerMemoryBytes512 MiBPositive finite number.
logRetentionDays7Integer from 1 to 365.

Settings are atomically written to settings.json. The allowlisted current resource projection is atomically written to current-snapshot.json and is considered stale fifteen seconds after its sampling instant. History is stored in history.sqlite with WAL mode and a thirteen-month retention window. History requests are limited to that window and to 50,000 points per series.

The implementation requires PLOINKY_INTERNAL_ROUTER_URL for private metrics and log requests. The repository does not define a separate user-facing configuration screen for that internal value.
