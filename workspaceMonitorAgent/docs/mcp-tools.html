MCP tools

Every tool runs through tools/workspace_monitor_tool.sh. The wrapper obtains the verified invocation actor and rejects the request unless the actor is an administrator.

The MCP configuration is the authoritative list of seven tools. It does not declare a public HTTP API owned by Workspace Monitor.

Reading Policy Audit and Router logs

The live view distinguishes loading, an empty successful read, available records, and a failed refresh. Loading appears only while a request is pending. When no Policy Audit records are present in the current live log, the viewer explains that policy changes and errors produce audit events; ordinary read-only browsing does not. An empty live log does not establish whether older events exist in retained archives, or whether audit logging is healthy or broken.

The log list's active: false metadata means no active file was present at that reload. The live option remains available and is labelled accordingly. The viewer checks for new records every two seconds, including when rotation has temporarily removed the live file. Newly available records appear automatically. Use the file selector to inspect an archive, and Reload to refresh the archive list.

Existing records remain visible while the same selection refreshes. A failed refresh marks them as potentially stale and displays the last successful check time, with an automatic-retry or Reload instruction. A successful response clears the error. Archive and search results pause live checking; Clear returns to the selected log. Switching views or leaving Workspace Monitor prevents older requests from replacing the current view and stops scheduled log checks.
