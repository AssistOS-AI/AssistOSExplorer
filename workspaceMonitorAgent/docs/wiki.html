Workspace Monitor terminology

Workspace Monitor

Workspace Monitor is the administrator-only agent that follows Ploinky's private workspace metrics stream, stores resource observations in SQLite, and exposes current snapshots, thresholds, history, and Ploinky log operations through its MCP tools. It does not grant access to ordinary participants.

Private metrics stream

The private metrics stream is the authenticated Ploinky endpoint consumed by the collector. It emits newline-delimited workspace snapshots containing Router, total, and runtime metrics. The agent signs the request with its private Router assertion and persists only an allowlisted current projection for authorized snapshot reads.

Runtime series

A runtime series identifies CPU or memory observations for one runtime. The collector derives the identifier from repository and agent names when available and stores it separately from aggregate workspace and Router series. A runtime series has no configured threshold of its own.

WAL

WAL means SQLite write-ahead logging. Workspace Monitor enables SQLite WAL mode so the history database can accept durable writes while read queries use the same persistent store. WAL is a storage setting, not a second history source.

Administrator

An administrator is the verified invocation actor admitted by the agent's role and local administrator identity checks. The MCP wrapper evaluates this actor before every snapshot, settings, history, or log operation; a client-supplied role alone is not authority.
