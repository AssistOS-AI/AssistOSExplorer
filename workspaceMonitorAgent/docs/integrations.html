Integrations

Explorer

The workspace-monitor IDE plugin is declared by the agent and mounted by Explorer when the runtime plugin policy enables it. The plugin is an administrator-only entry point, polls the agent's snapshot MCP tool for fresh resource data, and does not read agent storage, SQLite, or Ploinky files directly.

Ploinky metrics

The collector uses a private Router assertion to request the streaming workspace metrics route. Ploinky overlays current-run no-wait readiness on raw container state before publishing the stream; the projection retains both process liveness and semantic readiness so the Explorer dashboard counts only ready runtimes. The collector records the Router metrics separately, derives the workspace agent aggregate from available runtime metrics or from the total minus Router when runtime details are absent, and writes an allowlisted current projection for the administrator-only snapshot tool.

Ploinky logs

Log listing, reading, searching, and retention maintenance call Ploinky's private log service. Workspace Monitor sends signed requests and returns the service response; Ploinky remains responsible for log ownership, active files, and retained archives.

Boundary

The repository does not establish a public browser route or direct runtime-port contract for this agent. Consumers must use the configured MCP tools through Ploinky.
