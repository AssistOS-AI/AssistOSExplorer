Robot access
After you sign in to GitHub or save a token, your GitHub credentials are also saved to the selected RoboTeam robot so it can use git with GitHub.
  • Anyone with access to a robot can use the git credentials saved in it.
  • Prefer a GitHub token limited to the repositories the robot needs.
  • The credentials of the default robot are also used by ploinky update for private repositories.
  • Disconnecting GitHub here does not remove credentials from robots; use Remove from robot.
