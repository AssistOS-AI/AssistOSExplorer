Documentation / Operations

Operations

Robot management

robot_create, robot_list, and robot_delete manage owner-scoped robots by unique name. openDesktopForRobot starts a manual desktop for configuring the persistent coding-agent home.

Task tools

ModeStart / stop
DesktopstartDesktopTaskForRobot / stopDesktopTaskForRobot
BrowserstartBrowserTaskForRobot / stopBrowserTaskForRobot
Simple ALAstartSimpleALATaskForRobot / stopSimpleALATaskForRobot

Task operations return a taskId. Poll getTaskStatusForRobot. GUI task stop preserves the container; use stopDesktopContainerForRobot or stopBrowserContainerForRobot for removal.

First-use preparation

The first operation that needs Codex or a GUI automation server resolves the current release, installs it into /data/tool-cache, and validates it. Later starts reuse the active generation. When release lookup fails, RoboTeam uses the last valid generation if one exists.

Live work

getSessionUrlForRobotDesktop and getSessionUrlForRobotBrowser return authenticated session links. Take Control stops ALA only. Resume starts a new ALA task with a mandatory fresh-state observation.
