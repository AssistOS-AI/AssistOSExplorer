Robots & Runs

Create a robot once, then start it in browser or desktop mode whenever its persistent working environment is needed.

Persistent layout

PathPurpose
home/Mounted at /config; applications and robot-installed state persist here.
workspace/Persistent work files mounted under /config/workspace.
downloads/Persistent downloads mounted under /config/Downloads.
logs/Robot diagnostics.
runtime/Reserved transient runtime state.

Lifecycle

Create a robot with a name and optional specialization. Select Start Browser or Start Desktop to reserve a session window immediately, start the inner container, and navigate that window when Selkies becomes ready. The first run may wait while its OCI image downloads. If the browser blocks the new window, RoboTeam opens the session in the current tab. While a run is active, its button becomes Stop Browser or Stop Desktop, and the other mode stays disabled. Stopping removes the inner container without deleting files. Select Logs for bounded output.

MCP tools

ToolAction
robot_createCreate a persistent robot.
robot_listList owned robots and run status.
robot_startStart browser or desktop.
robot_stopStop the exact active inner container.
robot_logsRead bounded container logs.

At most ROBOTEAM_MAX_ACTIVE_ROBOTS runs are active globally and one per robot. Restart treats persisted robots as stopped and removes stale labelled containers.
