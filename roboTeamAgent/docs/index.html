RoboTeam Documentation

RoboTeam manages persistent robots and starts an observable browser or full Linux desktop for each one as an inner Podman container.

Product boundary

RoboTeam itself is one Ploinky-hosted outer container. A robot is an owner-scoped metadata record plus durable directories. Robot creation installs no software. Starting a graphical run attaches those directories to one shared, disposable desktop or browser image; stopping it preserves the robot's files.

Tasks are asynchronous and support live observation, Take Control, and Resume. First use prepares a persistent shared tool cache; later starts reuse it.

Development contract

DS001 defines coding style and test organization. Source changes that affect runtime behavior must update the corresponding HTML page and DS contract. Unit and integration tests live under tests/; image construction and supply-chain tests live with the separate container image definitions.
