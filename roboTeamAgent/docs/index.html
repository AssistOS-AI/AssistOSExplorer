RoboTeam Documentation

RoboTeam manages persistent robots and starts an observable browser or full Linux desktop for each one as an inner Podman container.

Product boundary

RoboTeam itself is one Ploinky-hosted outer container. A robot is an owner-scoped metadata record plus a durable home, workspace, downloads, and logs. Starting a robot creates exactly one disposable inner GUI container; stopping it preserves the robot's files.
