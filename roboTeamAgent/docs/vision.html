Product Vision

RoboTeam is the manager for a team of virtual employees. Each employee has a durable identity, a domain specialization, a private working area, selected skills, authenticated tools, and a desktop that the owner can enter directly.

Virtual employees

A virtual employee is represented by a robot profile. The profile keeps the employee's identity and working state stable across desktop restarts and one-shot tasks. Its specialization describes the field in which the employee works, such as research, publishing, software engineering, or administration.

Specialization metadata does not grant tools by itself. Executable specialization comes from task skills mounted by ALA from explicitly selected task repositories. This separation keeps a human-readable role distinct from the code and instructions that can act.

Human access and task execution

The interactive desktop exists for human configuration and oversight. The owner can open Chromium, sign in to permitted services, use a terminal, and arrange the employee's files. Desktop shutdown removes the graphical processes but retains profile state.

AdvancedLanguageAgent is the intended one-shot execution runtime. Its task sandbox remains ephemeral. The persistent profile workspace is mounted into that sandbox as an explicit task repository or writable folder, while unrelated profiles remain absent. RoboTeam's profile runtime does not define that launch protocol, browser automation, approval policy, or task scheduling contract.

Product boundaries

RoboTeam is one Ploinky agent. Robot profiles are application objects inside that agent; they are not additional Ploinky agents, aliases, or containers. Ploinky supplies hosting, authentication, persistent volume attachment, and Router-mediated access. RoboTeam owns profile identity, storage, desktop lifecycle, and user-facing operations.

The profile desktop provides Linux process and filesystem separation through a distinct numeric UID and private profile directories. This boundary is not equivalent to a virtual machine and does not make the trusted RoboTeam control service untrusted.
