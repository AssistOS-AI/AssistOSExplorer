Product Vision

A robot is a durable virtual employee whose visible workstation can be recreated without losing its home.

RoboTeam preserves identity, descriptive specialization, application configuration, work files, and authenticated browser state. Browser and desktop use separate custom images derived from public LinuxServer images. Both include the observable Selkies stack, so the current browser image is not substantially smaller than the desktop image.

This milestone provides workspace-scoped robots, administrator-controlled creation and deletion, GUI streaming, asynchronous ALA tasks, current-release computer-use-linux desktop control, current-package Playwright browser control, persistence, and cleanup. Runtime tools are prepared once in a shared persistent cache and every controller operates the same visible session.

Human takeover stops ALA while preserving the GUI; Resume starts a new task that first observes the user's current state.
