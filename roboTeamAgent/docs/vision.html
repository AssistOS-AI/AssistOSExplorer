Product Vision

A robot is a durable virtual employee whose visible workstation can be recreated without losing its home.

RoboTeam preserves identity, descriptive specialization, application configuration, work files, and authenticated browser state. Browser mode minimizes the graphical surface; desktop mode provides a complete Linux workstation. Both use the same observable Selkies model.

This milestone proves nested creation, GUI streaming, owner-scoped access, logs, persistence, and cleanup. A future controller can use Playwright for normal browser automation and Pelorus for non-DOM surfaces, but must operate the same visible session.

Human takeover, pause/resume arbitration, ALA task schemas, credential delegation, and side-effect approvals remain outside the current API.
