RoboTeam Wiki

RoboTeam

The single Ploinky agent that stores robots, operates inner Podman, and proxies observable GUI sessions.

Robot

An owner-scoped persistent record and directory tree with a name, specialization, home, workspace, downloads, logs, and on-demand run. “Profile” is not used for this object.

Robot home

The persistent directory mounted at /config in either GUI image.

Robot run

One temporary inner Podman container in browser or desktop mode. A robot has at most one active run.

Browser mode

A LinuxServer Chromium inner container streamed through Selkies.

Desktop mode

A LinuxServer Webtop Ubuntu XFCE inner container streamed through Selkies.

Ploinky agent

The outer deployable with identity agent:AchillesCLI/roboTeamAgent. Ploinky starts it, attaches storage, authenticates users, exposes MCP on port 7000, and routes the UI on port 3001.

Nested Podman

The Podman 6 engine inside the bounded RoboTeam outer container. It uses fuse-overlayfs and pasta and never controls host Podman.

Selkies session

The HTTP and WebSocket GUI produced by Chromium or Webtop and proxied through RoboTeam's authenticated route.
