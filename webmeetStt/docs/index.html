WebMeet STT

webmeetStt is an optional internal Faster-Whisper speech-to-text service. It is disabled by default and can be enabled by an administrator from Explorer Marketplace. The current text-only Meeting Secretary uses browser SpeechRecognition, with no STT fallback, and does not call this service. The STT service can apply the configured self-hosted DTLN denoise step before transcription.

Runtime boundary

The manifest attaches the service to the isolated webmeet bridge, exposes no browser route or physical-host port, and verifies its loopback /healthz readiness endpoint. Pinned Python dependencies are installed into the .data/webmeetStt volume mounted at /data and reused on later launches.

Read the specifications and Wiki for the service contract.
