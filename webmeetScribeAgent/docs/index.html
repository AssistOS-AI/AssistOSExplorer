WebMeet Meeting Secretary

webmeetScribeAgent is the text-only LiveKit worker for cumulative WebMeet notes. It accepts retry-safe directed final browser transcripts, validates their authors against the admitted room roster, stores a temporary encrypted recovery journal, and applies validated Markdown revisions to the active SCRIPTA document.

Analysis and recovery

Analysis runs at the configured time or word checkpoint and uses the current document structure, cumulative semantic memory, and uncompacted transcript. The worker does not receive an audio stream and does not expose a browser-facing MCP tool surface. Reset removes its recovery journal and disconnects the worker.

Runtime integration

Enabling the worker waits for AchillesIDE/liveKitServerAgent from the same repository. It uses that runtime's existing Router routes and shared generated LiveKit credentials.

The worker is disabled by default. An administrator can enable webmeetScribeAgent from Explorer Marketplace before using automatic Meeting Notes. Ordinary WebMeet meetings remain available without the worker. Browser SpeechRecognition supplies transcripts; the separate webmeetStt service is not required.

Ploinky supplies the standard PORT, Router descriptor, agent credential, and its one workspace-selected AchillesAgentLib source. The worker does not install or clone a private AgentLib copy. It shares the generated LiveKit API credentials with WebMeet and the LiveKit server. Its encrypted recovery journal is persisted through the .data/webmeetScribeAgent volume mounted at /data. See the specification matrix and the Wiki for the local contracts.
