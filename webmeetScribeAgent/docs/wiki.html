WebMeet Scribe terminology

WebMeet Scribe

WebMeet Scribe is the text-only Meeting Secretary worker dispatched for an enabled WebMeet room. It consumes directed transcript segments, reconciles cumulative meeting notes, reports activity, and applies revisions through WebMeet's secretary tools rather than writing the collaborative document directly.

Model Context Protocol

Model Context Protocol is the configured tool boundary used by the agent. Tool names and input schemas come from the local MCP configuration and execution remains subject to the agent's verified runtime authorization.

Ploinky

Ploinky starts the agent, supplies its runtime environment, and mediates authenticated invocation context. The agent does not treat client-declared identity as authorization.

Recovery journal

The recovery journal stores encrypted worker progress needed to resume a notes session after interruption. It is tied to the room and session lifecycle and is removed when the corresponding notes surface is cleared or finalized.

Holistic reconciliation

Holistic reconciliation rebuilds the cumulative notes result from the configured structure, bounded prior state, and accepted transcript instead of appending an isolated summary for each segment.
