AchillesIDE terminology

Explorer

Explorer is the static Ploinky application that provides the AchillesIDE browser workspace. It owns navigation, preview selection, source editing, runtime plugin mounting, and Explorer filesystem MCP tools. It does not own the protected domain state or authorization of coupled agents.

Ploinky

Ploinky is the runtime that starts workspace agents, publishes router routes, provides authenticated invocation context, and supplies the configured workspace environment. Explorer uses it as its deployment and trust boundary rather than exposing direct agent ports as the browser interface.

WebSkel

WebSkel is the Explorer frontend framework used to register components, apply presenter lifecycles, and mount runtime UI. Explorer components and agent-owned plugins use it to participate in the shared application shell while retaining their declared ownership boundary.

TinyMDE

TinyMDE is the Markdown source editor embedded by Explorer's markdown-editor component. It edits Markdown text in the browser and emits incremental changes through Explorer's workspace Markdown CRDT contract. TinyMDE does not own persistence, structured SOPLang nodes, or Office co-editing; Confidential DPU virtual paths use the DPU write contract.

Automerge

Automerge is the library used by Explorer's workspace Markdown and SCRIPTA collaboration services. Explorer stores canonical state in private workspace data, anchors plain-editor deltas to the heads for the visible text, merges concurrent changes, exposes a sanitized SCRIPTA collaboration projection, and materializes the converged result back to Markdown. Automerge is not used for Confidential DPU virtual Markdown or OnlyOffice documents.

Runtime plugin

A runtime plugin is an enabled IDE bundle described by `IDE-plugins/*/config.json`. Explorer discovers and policy-filters the bundle, resolves its components, and mounts it into declared host slots. The owning agent remains responsible for the domain operations reached through that UI.

DPU

DPU is the product identifier used by dpuAgent, the domain service for Confidential objects, secrets, research resources, jobs, access proposals, audit, and provenance. The repository does not define a longer expansion for the identifier. Explorer exposes DPU resources as virtual paths but sends protected actions to DPU tools, which evaluate the effective actor and permissions.

SOPLang

SOPLang is the structured document workflow used when a Markdown document requires metadata, document nodes, commands, variables, or references. Explorer leaves ordinary Markdown in source editing and opens the SOPLang-aware experience only through the explicit Advanced edit action.

Model Context Protocol (MCP)

MCP is the tool interface through which Explorer and coupled agents expose operations. Explorer MCP tools operate within configured workspace roots, while domain agents expose their own protected operations. Tool callers receive authority from verified runtime context, not a client-supplied actor field.

UserPersisto

UserPersisto owns durable local accounts, roles, authentication and application consent. Accounts are passwordless (email code, passkey, authenticator app or Google); the first completed sign-in becomes the administrator, and only that designated administrator may also use the deployment-configured administrator password. Optional Google verification resolves an immutable external identity to a local account; Google claims never replace local authorization or downstream subject IDs.

External identity

A verified upstream issuer/subject tuple bound to one local UserPersisto user. Email is a collision hint, never a binding key or permission to merge accounts. A first Google email-collision link requires explicit confirmation plus fresh proof of the existing account: a link code to its verified sign-in email, an enrolled passkey or authenticator, or the administrator password for the designated administrator. A Google account authoritative for exactly that verified email may link with confirmation alone.

Authentication attempt

A bounded browser flow with independent state, proof, parent context and deadline. A Google transaction can resume only while those proofs remain valid. ScriptaHub keeps a cancellable candidate session until a one-shot grant publishes the exact retained action; original-tab cancellation cannot roll back already committed remote identities.

SPA

SPA means single-page application. In AchillesIDE, Explorer keeps one browser application shell while routed paths and runtime plugins change the visible workflow without moving domain ownership into the browser.

UI

UI means user interface. Explorer UI collects user intent, presents results, and mounts shared components; protected agents remain responsible for authorization and domain mutations.

CRDT

CRDT means conflict-free replicated data type. The document and WebMeet workflows use Automerge-backed CRDT state to merge concurrent participant edits while preserving the owning collaboration contract.

ACL

ACL means access-control list. DPU evaluates effective actor permissions for protected objects and uses those rules when Explorer or OnlyOffice resolves Confidential resources.

JWT

JWT means JSON Web Token. Ploinky and OnlyOffice use signed, short-lived tokens for authenticated invocation or editor callback boundaries; a browser-provided token is not trusted without signature and session validation.

SQLite

SQLite is the embedded database used for Workspace Monitor history. It stores resource samples under the agent's persistent storage root and is configured with WAL mode for durable local history.

WAL

WAL means write-ahead logging. SQLite WAL mode lets Workspace Monitor retain its resource sample history while the collector writes and history queries read from the same database.

EDC

EDC is the research data connector represented by the DPU EDC adapter. DPU normalizes its resource results into the same research model and keeps provider credentials behind the configured secret reference.
