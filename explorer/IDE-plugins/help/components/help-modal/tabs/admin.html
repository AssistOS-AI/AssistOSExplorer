Workspace administration

Manage access and available capabilities

Administration controls are shown only to authorized users. If you do not see one of these areas, your account does not currently have permission to use it.

Users and roles

People create their own accounts by signing in; accounts have no passwords. In Settings → Administration, authorized users can find accounts, update names, assign roles, and remove accounts. New sign-ups start without Explorer access until an administrator assigns a role. A role determines which protected actions a user may perform.

Branding and audit

Administration also contains workspace login branding and audit settings. Use audit information to understand important activity without exposing confidential content.

Marketplace agents

Marketplace lists available agents. An admin can enable the capabilities the workspace needs and disable those that should not run.

Repository sources

The Repos area manages sources that provide agents, skills, or other workspace features. Install only repositories that your organization trusts.

Use care: Role changes, agent availability, and repository sources can affect everyone in the workspace. Confirm the intended scope before saving an administrative change.
