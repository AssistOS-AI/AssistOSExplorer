AI assistance

Ask for help with the right workspace context

Copilot is most useful when you start from the file or folder related to your task and explain the outcome you want.

  1. 1

    Choose the context

    Right-click the relevant file or folder and choose Open Copilot here. The conversation starts with that workspace location in context.

  2. 2

    Describe the result

    State what you want to create, change, understand, or review. Mention important constraints and ask Copilot to clarify anything that would change the result.

  3. 3

    Follow progress

    Some coding or research requests continue as longer-running tasks. You can keep the conversation focused, review progress, and continue supported tasks with a new instruction.

  4. 4

    Review the outcome

    Read proposed changes and generated content before accepting or publishing them. You remain responsible for deciding what belongs in the workspace.

Skills

Manage robot skills and skillsets in RoboTeam. Explorer Settings has no Copilot skill controls.

Specialized assistants

You can ask for coding, research, or other specialist help in natural language. Copilot selects an available specialist when the request needs one.

Behind the scenes: AchillesCLI manages Copilot conversations and coordinates separate specialist agents while Explorer supplies the selected workspace context.
